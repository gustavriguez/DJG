# Devin Gilbertson Portfolio — GitHub root build

This package is intentionally flat. Upload every file directly into the repository root, exactly as shown.

`index.html`, `site.css`, `site.js`, `content.js`, all other `.html` / `.js` files, and every `.webp` image must sit beside each other in the repository root.

The HTML does **not** reference an `assets/` folder. This matches the GitHub layout shown in the screenshots.

For GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Daily Garage photography
Daily Garage loads the rotating car photographs from Wikimedia Commons using each file's public Special:FilePath URL. The in-game photo credit links back to the corresponding Commons file page for source and license information.
